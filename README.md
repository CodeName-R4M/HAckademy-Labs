## 🔍 Overview

HAckademy-Labs is a versatile developer platform tailored for building interactive cybersecurity educational tools. It combines modern frontend tooling, a rich UI component library, and seamless backend integrations to accelerate development and ensure accessibility.

### Why HAcademy-Labs?

This project aims to simplify the creation of engaging, security-focused web applications. The core features include:

- 🎨 **UI Component Library**: Reusable, accessible React components for building cohesive interfaces.
- 🛠️ **Development Environment**: Configured with Vite, React, Tailwind CSS, and Radix UI for a smooth developer experience.
- 💾 **Backend Integrations**: Built-in support for Firebase and Supabase for authentication and data management.
- 📄 **TypeScript Configurations**: Ensures strict, modern, and compatible code across the project.
- 🎯 **Utility Functions**: Simplify styling and responsiveness, boosting productivity and code quality.

## 🚀 Getting Started

### ✅ Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or later)
- [npm](https://www.npmjs.com/)

### 🔧 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Hackademy-Labs.git
   ```

2. Navigate into the project directory:
   ```bash
   cd Hackademy-Labs
   ```

3. Install the dependencies:

   Using [npm](https://www.npmjs.com/):
   ```bash
   npm install
   ```

---

### ▶️ Usage

Run the project with:

Using [npm](https://www.npmjs.com/):
```bash
npm start
```

---

### 🧪 Testing

Hackademy-Labs uses the **{test_framework}** test framework. Run the test suite with:

Using [npm](https://www.npmjs.com/):
```bash
npm test
```
